# Contributing to picosign

The following is a set of guidelines for contributing to **picosign** and its package, which are hosted in the [picosign](https://github.com/vroncevic/picosign) on GitHub. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

## Code of Conduct

**picosign** project and everyone participating in it is governed by the [picosign code of conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code. Please report unacceptable behavior to [picosign](mailto:elektron.ronca@gmail.com).
